# 홈페이지 접속 테스트 가이드

JSTech 홈페이지(Next.js)를 로컬에서 실행하고 접속 테스트하는 방법을 안내합니다.

## 실행 환경

- 작업 디렉토리: `E:\workspace\opencode\JSTech\JSTech_Home`
- 프레임워크: Next.js 16 (App Router, Turbopack)

---

## 방법 1 — 개발 모드 (권장, 개발 중 빠른 테스트)

개발 중 코드를 수정하며 바로 확인할 때 사용합니다.

```powershell
cd E:\workspace\opencode\JSTech\JSTech_Home
npm run dev
```

- 접속 주소: **http://localhost:3000**
- 코드 수정 시 자동으로 반영됩니다(핫 리로드).
- 종료: `Ctrl + C`

---

## 방법 2 — 프로덕션 모드 (배포 전 최종 확인)

실제 배포 상태와 동일한 최적화 빌드로 확인합니다. 두 단계로 진행됩니다.

### 2-1) 빌드

```powershell
cd E:\workspace\opencode\JSTech\JSTech_Home
npm run build
```

### 2-2) 프로덕션 서버 실행

```powershell
npm run start
```

- 접속 주소: **http://localhost:3000**

## 참고 사항

- 접속은 배포 도메인 대신 **`localhost:3000`**을 사용합니다.
  - `NEXT_PUBLIC_SITE_URL`(기본 `https://jstech-home.vercel.app`)은 페이지 메타데이터/OG 태그에 쓰이는 값으로, 로컬 접속 주소와는 무관합니다.
- 브라우저에서 `http://localhost:3000/` 을 열면 홈 화면(히어로·서비스 소개·차별성·대표 프로젝트·CTA)이 표시됩니다.
- 존재하지 않는 경로(예: `/xyz`)는 커스텀 404 페이지가 표시됩니다.
