# 배포 및 운영 가이드 (GitHub + Vercel)

## 1. 배포 아키텍처 개요

```
[로컬 개발]  --git push-->  [GitHub 저장소]  --webhook-->  [Vercel 빌드·배포]  -->  https://jstech-home.vercel.app
```

- **소스 저장소**: https://github.com/jyuimp/jstech-home (SSH)
- **배포 플랫폼**: Vercel
- **프로젝트**: `jst-ech/jstech-home` (Vercel 계정: jyuimp)
- **프로덕션 URL**: https://jstech-home.vercel.app

## 3. GitHub 저장소 (원격 설정)

### 3-1) 원격 저장소 정보

현재 `origin`은 SSH URL로 설정되어 있습니다.

```
origin  git@github.com:jyuimp/jstech-home.git (fetch)
origin  git@github.com:jyuimp/jstech-home.git (push)
```

### 3-2) SSH 키 설정

push 인증에 사용하는 키는 **`C:\SPB_Data\.ssh\id_ed25519`** 입니다. 이 공개키가 GitHub(Settings → SSH and GPG keys)에 등록되어 있습니다.

- 공개키 파일: `C:\SPB_Data\.ssh\id_ed25519.pub`
- 등록된 GitHub 계정: `jyuimp`

SSH 설정은 `C:\Users\user\.ssh\config`에 있습니다.

```
Host github.com
    HostName github.com
    User git
    IdentityFile C:/SPB_Data/.ssh/id_ed25519
    IdentitiesOnly yes
```

### 3-3) push 방법

저장소에 `core.sshCommand`가 설정되어 있어 일반 명령만으로 push됩니다.

```powershell
git -C E:\workspace\opencode\JSTech\JSTech_Home push
```

> 자동으로 Windows OpenSSH(`ssh`)를 사용하도록 설정되어 있어, 배포 시 특별한 추가 인자가 필요 없습니다.

## 4. GitHub 자동 배포(CI) 연결 (완료 상태)

**현재 `jyuimp/jstech-home` 저장소가 Vercel 프로젝트에 연결되어 있으며, push 시 자동 배포가 동작합니다.**

확인된 연결 설정:
- Git 연결 타입: `github`
- 연결 저장소: `jyuimp/jstech-home`
- 프로덕션 브랜치: `master` ✅ (기본값인 `main`이 아닌 `master`로 이미 설정됨)
- GitHub 배포 활성화: `githubDeployment: 1`

**자동 배포 동작 실증 (2026-09-04)**: `master`에 연속 push만으로 자동 배포가 진행됨을 확인했습니다.

| push 커밋 | 자동 생성된 배포 URL | 상태 | 빌드 시간 |
| --- | --- | --- | --- |
| `c14053b` (배포 가이드 추가) | `jstech-home-o1t00oweg-jst-ech.vercel.app` | ✅ Ready / Production | 18s |
| `444e003` (자동 배포 상태 반영) | `jstech-home-m75mv3f2k-jst-ech.vercel.app` | ✅ Ready / Production | 14s |

> push를 하면 Vercel이 GitHub 웹훅으로 감지해 자동으로 빌드·배포하며, 프로덕션 URL(`https://jstech-home.vercel.app`)이 항상 최신 배포를 가리킵니다.

아래는 연결 방법과 참고 사항으로, 재연결 시 사용합니다.

### 4-1) 연결 방법 (대시보드)

1. **Vercel 대시보드** 접속: https://vercel.com/jst-ech/jstech-home
2. 왼쪽 사이드바에서 **Settings** → **Git** 선택
3. **Connected Git Repository** 섹션에서 **Connect Git Repository** 클릭
4. GitHub 계정(**jyuimp**) 선택 — 이때 **GitHub App 설치/허용** 프롬프트가 뜨면 승인
5. 리포지토리 목록에서 **`jstech-home`** 선택하여 연결

> ⚠️ **Owner 권한 필수**: personal 저장소의 경우 저장소 **Owner**(여기서는 `jyuimp`)만 Vercel 프로젝트를 연결/생성할 수 있습니다. Collaborator는 불가합니다.

### 4-2) repo가 목록에 안 보일 때 (GitHub App 권한 확인)

연결 화면에서 `jstech-home`이 안 보이면, Vercel GitHub App이 해당 repo에 접근 권한이 없는 것입니다.

1. GitHub 접속 → 프로필 **Settings** → **Applications**
2. **Vercel** 앱 → **Configure**
3. **Repository access**에서 `jyuimp/jstech-home`이 포함되도록 설정
   - `All repositories` 또는 `Only select repositories`에서 jstech-home 선택
4. **Save** 클릭 후 Vercel 대시보드로 돌아가 재시도

### 4-3) 프로덕션 브랜치 설정 (확인 완료)

**현재 이 프로젝트는 프로덕션 브랜치가 `master`로 이미 설정되어 있습니다.** (Vercel 기본값은 `main`이지만, 이 저장소 기본 브랜치가 `master`이므로 연결 시 `master`로 반영됨)

설정을 다시 확인/변경하려면:

1. Vercel 대시보드 → 프로젝트 → **Settings** → **Environments**
2. **Production** → **Branch Tracking**에서 브랜치 확인/변경 (현재 `master`)
3. 저장

**연결 완료 후**: 이후 `master` 브랜치에 push하면 Vercel이 자동으로 빌드·배포합니다.

## 5. 배포 방법

### 5-1) 자동 배포 (Git 연결 완료 후)

`master` 브랜치에 push하면 Vercel이 자동으로 프로덕션 배포를 수행합니다.

```powershell
git -C E:\workspace\opencode\JSTech\JSTech_Home add .
git -C E:\workspace\opencode\JSTech\JSTech_Home commit -m "변경 사항 설명"
git -C E:\workspace\opencode\JSTech\JSTech_Home push
```

### 5-2) 수동 배포 (Git 연결 전 또는 즉시 반영이 필요할 때)

Vercel CLI로 프로젝트를 연결해 직접 배포합니다.

```powershell
cd E:\workspace\opencode\JSTech\JSTech_Home
vercel --prod
```

- 최초 1회 프로젝트 연결 시 팀/프로젝트 선택 프롬프트가 뜹니다.
- 계정 로그인 상태: `vercel whoami` → `jyuimp`

## 7. 문제 해결 (Troubleshooting)

### 7-1) GitHub push SSH 인증 실패 (`Permission denied (publickey)`)

**원인**: push가 쓰는 SSH 키가 GitHub에 등록된 키와 다르거나, 비밀키 파일 권한이 열려 있는 경우.

**확인/해결**:
1. `C:\Users\user\.ssh\config`의 `IdentityFile`이 GitHub에 등록된 키와 일치하는지 확인
   - GitHub 등록 키의 공개키 내용(`C:\SPB_Data\.ssh\id_ed25519.pub`)과 일치해야 함
2. 비밀키 파일 권한 확인 (다른 사용자 접근 불가해야 함):
   ```powershell
   icacls "C:\SPB_Data\.ssh\id_ed25519" /inheritance:r /grant:r "$env:USERNAME:F"
   ```
3. 인증 테스트:
   ```powershell
   ssh -o BatchMode=yes -T git@github.com
   # 정상: Hi jyuimp! You've successfully authenticated...
   ```

### 7-2) git push 시 `Host key verification failed`

**원인**: git이 사용하는 ssh가 known_hosts에 github.com 호스트 키를 갖고 있지 않은 경우.

**해결**: Windows OpenSSH ssh를 명시적으로 사용하도록 `core.sshCommand` 설정 (이미 이 저장소에 적용됨).

```powershell
git -C E:\workspace\opencode\JSTech\JSTech_Home config core.sshCommand "ssh -o StrictHostKeyChecking=accept-new"
```

### 7-3) Vercel Git 연결 실패 (`Failed to connect ... to project`)

**원인**: Vercel GitHub App이 repo에 접근 권한이 없음 (App 미설치 또는 repo 미포함).

**해결**: **4-2절**의 GitHub App 권한 확인/부여 후 재시도.
